WordPress Plugin for a Bible Reading interface, initially using the Bible Brain / Digital Bible Platform API.

== Description ==

The Bible Plugin provides a Scripture reading interface for WordPress using the Bible Brain (formerly Digital Bible Platform) API. Designed with flexibility and future expansion in mind, it aims to support local scripture bundles, multilingual content, and lightweight API use.

== Requirements ==

* PHP 7.4 or higher
* PHP extensions:
  * json
  * gettext
  * zip

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the “Plugins” menu in WordPress.
3. Navigate to plugin settings and configure any necessary API keys or data source preferences.

== Frequently Asked Questions ==

= Does this plugin work without an internet connection? =
Not yet. Offline USX/XML support is on the roadmap.

= Can I change Bible versions or languages? =
Yes, depending on the API and your configuration options.
